# Code de conduite

Nous accueillons les contributions avec respect, quels que soient l’expérience,
la langue, l’origine, le handicap, l’âge, les convictions, le sexe ou le genre.
Écouter les désaccords, expliquer les décisions et reconnaître les corrections.

Le harcèlement, les menaces, les attaques personnelles, la divulgation de données
privées et les propos discriminatoires sont interdits dans les espaces du projet.
Ne pas publier de données familiales réelles pour illustrer un différend.

Pour signaler un incident, contacter en privé le responsable du dépôt par un moyen
qu’il affiche sur son [profil GitHub](https://github.com/steveprudhomme).
En l’absence de canal privé disponible, utiliser le signalement GitHub pour les
contenus abusifs ; ne pas publier les détails sensibles dans une issue.
Un canal dédié et une personne de recours indépendante restent à établir.

Le responsable accuse réception lorsque le canal le permet, limite l’accès aux
informations, entend les parties et documente la décision sans exposer les victimes.
Selon la gravité : rappel, retrait du contenu, restriction temporaire ou exclusion.
Une personne impliquée se récuse si un autre mainteneur peut traiter le dossier.
Un réexamen peut être demandé par le même canal avec de nouveaux éléments.
Le projet ne promet pas de délai de réponse ni une confidentialité absolue des plateformes.
