# RFC 0001 — Base expérimentale SGAN 0.1.0

- Statut : Proposee
- Date : 2026-11-13
- Version visée : prochaine révision de 0.1

## Objet

Soumettre à la discussion la base expérimentale publiée : dossiers à plat,
identifiants permanents, notation longue, trois fichiers individuels, manifeste
central, références documentaires et assertions motivées.

## Choix provisoires

La notation longue rend les segments explicites et les identifiants indépendants
permettent de conserver une personne unique malgré plusieurs chemins généalogiques.
Le manifeste central simplifie le contrôle des références ; il peut devenir volumineux.
La notation compacte et des notices réparties sont des alternatives à évaluer.

## Évaluation attendue

Tester les noms de dossiers sur Windows, les rangs dépassant neuf, les unions
multiples, les implexes, les références communes et les changements de personne racine.
Évaluer les exemples synthétiques et proposer les migrations requises.

## Décision

Aucune acceptation communautaire n’est déclarée. La première publication est
une base de discussion, sans consultation achevée ni homologation.
